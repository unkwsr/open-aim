# Black Market Butterfly

The user requested `Downloads/butterfly.har` instead of the skipped Karambit.
The retained capture includes the matching Black Market/Infantry2 mesh, FP hand
clips, GN knife clips, four body PBR maps, alternate color textures and Jett arms.
No recorded URL is fetched. Exact capture ordinals, sizes and SHA-256 hashes are
in `tools/skin-converter/butterfly-source/capture-provenance.json`.

Restart `Start Test Game.cmd`, choose **Melee skin → Black Market Butterfly**, and
enter a scenario. Equip, idle, all three light attacks, heavy attack and inspect
(`Y`) use the matching model/hand/knife assets. Both folding handles are skinned
and sampled with the hand clip on the same timeline. The supplied inspect is
included because this model and animation set match. Original/native movement
additives remain; this capture does not provide separate Butterfly walk/run or
fast-equip clips. The later user-supplied WAV pack adds matching equip, inspect,
left-click and right-click audio. Light attacks start `attack1.WAV`, followed
when that 0.5805-second clip ends by `afterleftclickattackanimationsound.WAV` for the handle/
recovery sequence. Heavy/right-click uses `attack2rightclick.WAV`. The supplied
bytes are copied without re-encoding and only play while Butterfly is selected.

The full 6,204-triangle model and original-resolution color, normal, ORM and
emission PNG bytes are preserved. No geometry fitting, simplification, texture
resampling, artificial projection offset or custom tint was added. GLB Blender
24 fps timelines are converted to the existing 60 fps authored time convention
at factor 2.5, using the same pipeline as the accepted fan import. Native attack
cadence, damage and equip-readiness timing are unchanged; visual clip tails may
continue after readiness and are interruptible by attacks/switching.

The normal-arm mesh remains byte-identical. Butterfly's Jett view uses the
capture's matching Jett mesh and color texture, with weights remapped by joint
name onto the shared arm rig. Jett-only corrective influences follow their shared
ancestor. The existing native 112-bone ability rig still evaluates dash/smoke;
its common animated poses are copied to the visible shared rig without drawing
the incompatible auxiliary mesh. All seven existing dash/smoke animation payloads
and their indices remain unchanged. This adapter is restricted to Butterfly.

Both loader routes are generated by `build-viewmodel-loader.mjs` through
`extend-butterfly.cjs`. Existing cache keys already include the selected melee
skin. The three menu choices are Default knife, Silkleaf Fan and Black Market
Butterfly. A saved choice from the discarded Karambit experiment migrates to
Butterfly when the customization script loads. Other saved choices are retained.

## Steel readability and material revision (2026-10-27)

User showed the pitch-black shaded side and a bright steel/dark-handle reference,
then asked for a less cartoon-like finish. The blade and handles now use separate
material groups selected by the authored Handle_Blade skin weights. Every source
triangle remains; only index order/groups change. This adds one weapon draw group.
Positions, normals, UVs, skin weights, textures, rigs and animation clips are kept.

The final blade material uses metallic factor .85, roughness factor .42, normal
strength .65, restrained albedo exponent .75/floor .015 and environment intensity
2.3. Handles use metallic .65, roughness .7, exponent .9/floor .004 and intensity
1.3. The large intermediate brightness floor was removed after the user's feedback.
The captured Kingdom Archives viewer (HAR record 5) constructs the matching PBR
normal map with positive Y scale and flipY=false. Butterfly now matches that normal
direction; the initial import had inherited the fan's negative Y scale.

Butterfly alone uses a 128×64 neutral reflection texture with broad soft light
cards. This restores directional metallic highlights instead of depending on a
large diffuse brightness lift. It is a static viewmodel reflection approximation,
not a reflection of the current map. It is built once per model and disposed by
the existing environment cleanup. No emissive/glow or global lighting was added.

Controlled native-renderer masks on both visible blade faces measure mean steel
luminance about 139/255 versus the original ~19–23; handles remain ~51–53. This is
one fixed lighting/camera fixture, not an exact match across maps or displays.
Before/after captures are `previews/butterfly/materials-{right,left}-{before,after}.png`.
`butterfly-material-results.json` records part masks and results. All 56 animation/
hand/ability cases and six cold/warmed switching cases pass after this revision;
no WebGL error. Warmed switching still adds zero shader/texture/geometry loads in
the fixture. Live appearance/feel and FPS remain for the user to judge.

## Supplied action audio (2026-10-27)

`tools/skin-converter/import-butterfly-audio.py` copies the five WAVs from
Downloads to `app/mods/media/blackmarket-butterfly` byte-for-byte and records
their hashes and stream metadata in `butterfly-audio-import.json`. The audio
controller decodes each clip once, routes by selected melee skin and simulation
action, deduplicates render frames, stops scheduled/active voices on interruption,
pause or weapon change, and uses the game's existing audio master destination.
Default knife and Silkleaf Fan routing remain separate.
